# Datos del especial El Niño 2026-2027 (Primicias)

Data publicada para el especial de Primicias sobre El Niño. Los archivos de `*/data/out/` y `parroquias/` se leen desde:

```
https://raw.githubusercontent.com/tefaceli/fenomeno_nino/main/<ruta del archivo>
```

Coordenadas en EPSG:4326 y horas de Ecuador (UTC-5). Límites territoriales: parroquias del CNE (2025).

**Fuentes:** Secretaría Nacional de Gestión de Riesgos (Alístate Ecuador), INAMHI (advertencias meteorológicas, vía GeoGLOWS), MAG (susceptibilidad a inundaciones), SGR (susceptibilidad a movimientos en masa) e INOCAR (predicción de mareas).
